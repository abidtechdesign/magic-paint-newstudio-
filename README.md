# 🎨 Magic Paint Studio

**An interactive, gesture-controlled digital painting experience.**

Magic Paint Studio is an experimental creative application that lets users draw, paint, and create digital artwork using real-time hand gestures through their webcam.

Explore a new way of interacting with a digital canvas — without needing a mouse or touchscreen.

**[Try Magic Paint Studio](https://magic-paint-newstudio.vercel.app/)**

**GitHub Repository:** [magic-paint-newstudio](https://github.com/abidtechdesign/magic-paint-newstudio-)

## ✨ Features

### 🖐️ Gesture-Based Controls

Control your canvas using six simple hand gestures:

| Hand Gesture | Action |
|---|---|
| ☝️ Index Finger Up | Draw on the canvas |
| ✊ Closed Fist | Pause drawing |
| 👍 Thumbs Up | Undo last stroke |
| 👎 Thumbs Down | Clear canvas |
| ✌️ Peace Sign | Change to next colour |
| 🤟 Three Fingers | Change to next brush |

Gestures are designed to trigger once per action, helping prevent accidental repeated interactions.

### 🖌️ Creative Brushes

Explore five different painting styles:

- **Neon** — Glowing neon strokes.
- **Rainbow** — Colourful rainbow strokes.
- **Liquid** — Fluid-inspired painting effects.
- **Galaxy** — Cosmic-inspired visual effects.
- **Fire** — Fiery glowing strokes.

### 🎨 Customization & Canvas Tools

- Colour palette selection.
- Adjustable brush sizes.
- Gesture-based colour and brush switching.
- Undo and clear canvas controls.
- Download artwork as PNG.
- Interactive particle effects.

### 📷 Camera & Input Support

- Real-time webcam hand tracking.
- Visual hand landmark tracking.
- Mouse and touchscreen drawing support.
- Camera controls for starting and stopping hand tracking.

## 💻 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/abidtechdesign/magic-paint-newstudio-.git
```

### 2. Navigate to the project

```bash
cd magic-paint-newstudio-
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

If your local project requires a Gemini API key, create a `.env.local` file using the variables documented in `.env.example`.

Never commit API keys or other secrets to GitHub.

### 5. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to explore the application.

## 📦 Production Build

To create a production build:

```bash
npm run build
```
